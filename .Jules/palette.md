## 2025-05-22 - API Hypermedia for Asynchronous Flows
**Learning:** In headless/backend-only projects, API UX is defined by discoverability. Providing resource-specific hypermedia links (like `captcha_url`) guides consumers through multi-step processes without them having to hardcode URL patterns.
**Action:** Always include hypermedia links when an API resource enters a state that requires a specific next-step action from the client.
