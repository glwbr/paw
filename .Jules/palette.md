## 2025-05-14 - API UX in Backend-only Projects
**Learning:** In projects without a frontend, API UX is defined by discoverability and actionable error messages. Providing resource-specific hypermedia links (like `captcha_url`) guides consumers through asynchronous multi-step processes without requiring them to construct URLs themselves.
**Action:** Always include hypermedia links for related resources or next steps in asynchronous API responses to improve developer experience and self-discoverability.
