## 2025-05-15 - Hypermedia links in backend-only projects
**Learning:** In headless/backend-only projects, API UX is defined by discoverability; provide resource-specific hypermedia links (like `captcha_url`) to guide consumers through multi-step asynchronous processes.
**Action:** Always check if an asynchronous process requires manual intervention and provide a direct link to the next step in the resource representation.
