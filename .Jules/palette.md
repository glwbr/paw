## 2025-05-15 - API discoverability via hypermedia links
**Learning:** In headless projects, API discoverability is a key UX component. Providing resource-specific links (like `captcha_url`) guides developers through complex asynchronous flows.
**Action:** Always include hypermedia links for state-dependent actions in API responses.

## 2025-05-15 - Fail-fast validation for better DX
**Learning:** Immediate validation of input (like NFC-e access keys) prevents unnecessary background processing and provides instant, actionable feedback.
**Action:** Use existing domain logic to validate inputs at the API entry point.
