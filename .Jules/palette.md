## 2025-05-14 - API Discoverability as UX in Headless Projects
**Learning:** In headless or backend-only projects, UX is synonymous with DX (Developer Experience). API discoverability through hypermedia links (like `captcha_url`) and failure-fast validation (like immediate access key check) significantly improves the integration experience by providing clear, actionable paths and reducing polling-induced uncertainty.
**Action:** Always look for multi-step asynchronous processes and provide resource-specific links to guide the client to the next required action.
