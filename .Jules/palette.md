## 2025-03-21 - Discoverability in Headless APIs
**Learning:** In backend-only projects, API UX is defined by discoverability. Providing resource-specific hypermedia links (like `captcha_url`) guides consumers through multi-step asynchronous processes without them needing to hardcode URL patterns.
**Action:** Always look for opportunities to add hypermedia links in async API responses to improve developer experience (DX) and self-discoverability in headless projects.
