## 2026-07-10 - Hypermedia Discoverability and Fail-Fast Validation in Headless APIs
**Learning:** For backend-only and headless APIs, Developer Experience (DX) and discoverability function as user experience (UX). When multi-step asynchronous processes require interactive steps (such as CAPTCHA solving), serving relative hypermedia links like `captcha_url` directly in the resource status guide the consumer automatically and prevent opaque documentation lookup. Additionally, immediate fail-fast validation of identifiers (like NFC-e 44-digit access keys) at the entry point prevents silent background failures, dramatically improving feedback loop times.
**Action:** Always provide self-describing resource links to guide clients through complex multi-step state machines, and enforce synchronous input validation as early as possible on the API boundary.
