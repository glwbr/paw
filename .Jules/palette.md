## 2026-07-10 - Hypermedia Discovery & Validation in Headless APIs
**Learning:** In headless or backend-only projects, API UX is defined by discoverability and clean validation error messages. Offering resource-specific hypermedia links (such as `captcha_url`) guides consumers through multi-step asynchronous processes like receipt imports, eliminating the need for clients to hardcode polling URLs and decreasing overall coupling. Immediate, fail-fast input validation ensures clients receive clear error messages before triggers initiate expensive or long-running background tasks.
**Action:** When designing asynchronous or multi-step API endpoints, always provide relative transition URLs dynamically in the resource representation. Implement immediate, robust request-body and pattern validation at the handler boundary to return fast, actionable public errors.
