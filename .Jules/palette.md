## 2026-06-04 - API Discoverability and Fast-Fail Validation
**Learning:** In backend-only or headless projects, UX is defined by API discoverability (e.g., providing action links like `captcha_url`) and immediate, actionable validation errors.
**Action:** Always include hypermedia-like links (Operation-Location, resource-specific URLs) to guide API consumers through multi-step processes.
