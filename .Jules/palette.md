## 2026-07-10 - Self-Discoverable Hypermedia and Fast-Fail API UX
**Learning:** Headless API users benefit immensely from self-discoverable hypermedia links and fast-fail input validation. Providing a conditional `captcha_url` when a receipt import enters the `waiting_captcha` state saves the developer from hardcoding complex state transitions or path constructions, leading to a much smoother developer experience (DX). Meanwhile, immediate 400 Bad Request responses with descriptive, public error messages for malformed input (such as 44-digit access keys) avoid starting expensive background worker tasks that are doomed to fail.
**Action:** Always design API endpoints for multi-step processes with relative hypermedia links, and perform immediate validation on key identifiers before delegating work asynchronously.
