## 2025-05-22 - [Headless API UX/DX]
**Learning:** In backend-only or headless projects, UX is primarily expressed through Developer Experience (DX). Micro-UX improvements include hypermedia links for discoverability in asynchronous processes and "fail-fast" validation of complex inputs like NFC-e access keys.
**Action:** Always provide resource-specific links (like captcha URLs) to guide API consumers, and validate identifiers early in the request lifecycle to provide immediate, actionable feedback.
