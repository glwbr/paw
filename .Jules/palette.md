## 2026-07-10 - [Discoverable Captcha URL for Headless API Ingestion]
**Learning:** In headless or API-only environments, UX is synonymous with DX (Developer Experience). For multi-step asynchronous processes like receipt import where a CAPTCHA solver may be required mid-flow, returning conditional, resource-specific hypermedia links (such as `captcha_url` only when status is `waiting_captcha`) simplifies client implementation. It avoids requiring clients to manually construct URLs, reduces hardcoding, and guides users/developers intuitively through the state machine.
**Action:** When designing stateful, asynchronous HTTP APIs that require external interactive steps (like CAPTCHA or multi-factor auth), always include dynamic hypermedia URLs representing the next immediate step conditionally based on the resource state.
